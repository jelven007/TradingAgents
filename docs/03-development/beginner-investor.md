# 入门投资者使用体验：系统分析与改进契约

本文记录2026-10-25上一轮入门路径的分析和验收，8782已成为保留入口。最新入口为 **http://127.0.0.1:8783/**；后续内置证券目录、买卖问题、有界真实研究和复验详见[股票研究改进](stock-research-usability.md)。下方三个控件、批准清单和当时未做真实调用等数字均为上一轮历史证据。本轮目标是“全面分析下当前系统，改进成可以给一个入门级投资者快速上手的工具”，保留报告、个人关注与核实笔记能力。

此文为historical explanation，产品/QA责任角色面向工程读者保留原始分析和验收；后续变更只追加当前链接，不把旧实验说明改成新运行证据。当前操作以工作台how-to为准。

## 1. 现状结论

系统已经具备可执行研究、固定输入、调用限额、证据留存、质量检查、报告复核、评估及账号权限。主要体验仍按研究团队与运营者的工作方式组织。功能可操作，首次使用时却需要承担过多概念学习和参数选择。

改进前本机入口8781已配置真实模型版本，已有用户账号与记录。本次分析和验收不修改用户密钥、不向正式空间加入测试账号、不试调用付费模型。浏览器基线在556×665下实际进入演示并打开创建页：默认15个字段、19个表单控件，执行限额默认展开；首页首先提供研究员/复核员/运营员切换，工作流涉及“固定版本”“评估”等概念。

| 环节 | 当前表现与证据 | 入门者的障碍 | 本次改进 |
|---|---|---|---|
| 登录前 | 主文案先要求配置模型；登录、演示、高级凭据共存 | 不知道工具能解决什么，也不懂模型配置 | 明确“理解公司、阅读依据和风险”，突出无配置的实际示例入口；登录继续可用 |
| 首页 | 研究任务、待复核、已发布指标；专业工作流及身份切换 | 缺少自己的下一步，零计数不能帮助理解 | 默认入门首页：开始研究、继续最近研究、个人关注清单、简短上手指引 |
| 创建研究 | 模板、日期、资产、用途、基准、币种、实验、团队、限额及持仓 | 每个字段虽有来源，仍要理解19个控件 | 默认快速模式：选择研究对象、问题、关注期限；其余沿用模板并可查看/编辑 |
| 标的输入 | 主要依赖代码和批准清单 | 知道公司名但不知道股票代码 | 在批准范围内支持名称/代码搜索；名称属于系统预置说明，清单来自配置 |
| 等待 | 展示模型调用、节点及任务ID | 不知道系统现在在做什么、能否离开 | 用真实阶段解释“整理价格/新闻/公司资料”，完成后明确进入报告，失败有具体恢复入口 |
| 读报告 | 默认长篇Markdown，评级“买入/增持”较突出 | 容易将评级理解为操作命令，难辨依据与缺口 | 默认先读简明概览：研究对象/期限、观点含义、原文依据、风险、数据状态和下一步 |
| 数据可靠性 | 已有block/review规则，信息分散在质量页 | 容易把“执行完成”理解为“判断可信” | 缺口、过期、退回/撤回与合成来源优先呈现；完整依据与规则始终可查 |
| 持续使用 | 任务/报告列表；没有个人关注对象与研究笔记 | 看完即结束，下次不知道继续看什么 | 增加按身份隔离、持久化的关注清单及核实笔记；连接实际最近研究 |
| 学习 | 页面里有提示，没有统一术语说明 | “基准”“交易日”“评级”“持仓占比”不易理解 | 可搜索的入门指南和上下文解释；基于系统定义，明确区分研究、核验与交易 |
| 专业能力 | 运营、审核、模板、模型、评估均开放在角色导航 | 主路径被大量非首次使用功能占据 | 入门/专业界面可随时切换；完整参数、授权、复核和评估继续工作 |

当前系统也有业务边界：不是实时行情终端，外部行情和模型取决于已配置服务；价格新鲜度、来源许可、公布时间和论据核验不能仅靠界面确认；日级研究期限不等于长期理财方案；已有评估闭环不能证明未来投资效果。界面应把这些实际数据状态讲清楚，不能加入虚构报价、胜率、收益保证或评分。

## 2. 使用路径

首次使用：打开入口 → 体验实际示例或登录 → 选择名称/代码和研究问题 → 核对默认期限及来源 → 开始执行 → 阅读观点、依据与缺口 → 保存关注及待核实事项。

回访：打开个人关注/最近研究 → 继续未完成的任务或读上一次报告 → 需要更新时重新研究。关注清单不自动下单、不自动发送消息，也不声称提供实时价格。

专业使用：切换专业界面 → 继续完整参数、模板/模型配置、复核、评估与运营。界面模式只是个人显示偏好，不改变业务权限。

## 3. 实现范围和约束

### 入门首页与引导

- 默认为研究员/管理员提供入门界面；复核/运营角色可保留符合职责的专业默认值。模式选择可记住，浏览器只存显示偏好，不存账号密钥、持仓或研究笔记。
- 首屏一个明确主要行动：开始了解公司。示例来自现有隔离演示服务，清楚标注合成数据与练习用途。
- 展示本人最近研究及继续入口；不把工作空间其他人的任务计数包装为本人研究。
- 模型未配置、没有可研究模板或缺少权限时给出实际设置入口或示例入口，避免无解释的禁用按钮。

### 快速创建与完整参数

- 快速模式使用与专业模式相同的草稿、校验、幂等键和`POST /research`，保持固定输入及限额执行。
- 支持批准清单内名称/代码搜索和原始代码输入。公司名称为系统预置辅助信息，未知名称不猜测映射；配置未批准的代码仍拒绝。
- 研究问题用“了解这家公司”“跟踪消息或事件”等普通表达，对应模板实际允许用途。持仓复核仍必须补全必要账户估值，不能自动假定空仓或价格。
- 期限快捷选项可使用5/20/60个交易日，并保留模板默认值及自定义。说明“约一周/一月/三月”只是股票交易会话的近似，并非收益保证或持有建议。
- 模板、日期、币种、基准、团队和限额默认沿用配置，确认区解释来源及预留预算；可以展开完整字段修改。所有原字段与配置往返草稿保留规则继续有效。

### 报告易读层

- 新增只读概览，由已核验文件完整性的固定报告、研究输入、结构化质量结果及决策状态生成，不调用额外模型，不修改原报告。
- 原文节选明确标注来源字段；缺少理由、反方或风险说明时显示未提供，不能生成看似完整的投资判断。
- “Buy/Overweight/Hold/Underweight/Sell”解释为研究观点及与基准的关系。显示数据缺口、草稿或过期状态后再给出观点，不能把“发布”解释为无风险或收益保障。
- 价格只有在本次结构化证据可支持时显示，并带日期、币种确认状态和合成/真实来源说明。币种未知、价格冲突或没有价格证据时不展示虚假的当前行情。
- 操作为阅读完整依据、查看质量问题、保存关注及核实笔记。复核仍由具有权限的另一身份完成，不能由阅读确认替代。

### 个人关注与笔记

- 使用SQLite按`workspace + principal.subject + symbol`隔离；请求不能指定另一个所有者。读取与修改分别沿用既有研究读取/创建权限，演示和正式数据隔离。
- 保存、编辑笔记、移除、刷新、重新登录和重启均保留正确结果；最多100个关注对象，笔记长度受限。
- 新增对象在当前批准清单内；清单之后改变时已有笔记仍可读取和移除，重新研究须重新通过批准范围校验。
- 展示本人相关任务/报告的真实状态及日期，不能把最后报告中的价格称为实时价格。

### 术语与错误恢复

- 入门指南提供代码/名称搜索、评级、基准、交易日、数据时间、草稿与复核、持仓占比的简短解释；支持搜索和实际研究入口。
- 失败解释只基于已留存类别；不能从一个通用ValueError编造“行情断线”原因。提供检查服务、查看限额、调整输入后重做等合适入口，保留草稿。
- 模型密钥、微美元、实验标识、JSON、哈希和服务路径放在专业或详情中；投资者需要做预算/数据决策的信息不能隐藏。

## 4. 验收契约

至少三轮独立实际操作，覆盖桌面、手机竖屏及横屏，最终成功后交付。全量回归、安装包及冷重启按改动完成必要检查。检查包括：

1. 首次进入无需解释研究术语即可找到示例或开始按钮；快速模式默认只要求关键投资问题，详细参数全部可展开操作。
2. 名称、代码、期限、用途及模板默认值实际进入任务；不批准的代码、超限及无效输入仍正确拒绝。
3. 快速/专业切换、模板/模型往返及错误恢复不丢失草稿；专业原流程、权限和执行限额保持有效。
4. 实际生成报告，概览与固定原文及质量状态一致；缺失、阻断、过期和合成报告不得出现虚构判断、当前价或可信评分。
5. 关注、笔记编辑、移除、重复添加、刷新、重新登录及服务重启均操作成功；跨身份、跨工作空间和正式/演示之间不可串读或串写。
6. 术语搜索和返回研究可操作；手机首屏按钮可见，键盘焦点明确，无横向溢出、遮挡、空白页或应用脚本错误。
7. 正式账号、模型配置及已有研究不被测试修改；验证使用隔离QA和合成任务，真实外部服务是否验证单独记录。

界面操作与理解的改善以可见字段、实际完成路径和测试证据评价；未经真实入门用户访谈，不声称已证实提升投资判断能力。

## 5. 实际交付与验收结果

快速创建默认只展示三个表单控件，相比原19个减少16个。公司名称匹配只在当前批准清单内进行；用途与期限、所有完整参数及设置往返共用同一份草稿。日期、基准、币种、团队、预算和模板来源在确认区可查，完整参数仍可逐项操作。

默认首页、任务阶段说明、报告简明概览、关注/笔记和入门指南已经接入实际接口。报告节选保留原文来源，缺失的支持、反方和风险段落明确显示未提供；价格有数据日期和合成标志。身份模式只是显示偏好，研究员不能因切换界面获得自审权限。

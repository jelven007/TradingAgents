# 浏览器研究工作台

初始实现日期：2026-10-24，基线 `acc6b0e`；2026-10-25已加入可配置输入、入门投资者路径及有界股票研究。访问 **http://127.0.0.1:8783/** 即可使用中文工作台。前端为React/Vite，生产资源及证券目录打包进Python wheel，启动时不依赖Node或CDN；JSON API路径保持兼容。

读者为投资者/管理员，产品与前端责任角色依据实际UI、服务路由维护；每次界面/入口变化及合并前复核。步骤为当前how-to，历史UI证据只见验证记录，不将合成示例作为真实行情。

## 本地使用

```bash
.venv/bin/python -m cli.main managed \
  --templates config/examples/managed-templates.json serve --port 8783
```

本机当前入口为 **http://127.0.0.1:8783/**，使用已有账号和密码登录；也可直接点击“体验演示”。全新安装首次运行时可创建首个管理员账号。刷新仍保持登录，无需导入token文件。登录密码用于工作台，模型API Key仍在设置中单独填写；已有配置直接使用。旧8782及更早服务保留。

研究员与管理员默认进入入门界面。点击“开始了解公司”，按市场和名称/代码搜索，点击选择股票，再选择买入机会、持有理由、卖出风险或一般了解。系统带入原始币种和推荐基准；显示货币预置美元/人民币，期限可用5/20/60交易日建议。默认路线最多8次调用（含重试），提交前核对预算，执行后自动生成报告；资料不足时明确说明。简明概览突出结论、依据、风险与重新判断条件，原文节选可展开。详细证据见[股票研究改进](stock-research-usability.md)。个人关注和笔记只属于当前身份，刷新、重新登录和重启仍保持。

顶部“专业界面”可恢复原研究、复核、评估、运营和设置流程。显示模式只保存在浏览器作为偏好，不改变账号权限；复核员/运营员默认使用专业界面。详细分析、操作及三轮以上验证见[入门投资者改进](beginner-investor.md)。

管理员可在“设置 → 账号管理”创建研究员、复核员、运营员或其他管理员账号。导航只显示角色可访问的页面；管理员虽可复核其他作者报告，仍不能自审。研究员可创建/执行研究、登记报告与评估，复核员以自己的账号批准/发布，运营员查看运营与审计。页面“退出登录”立即撤销当前会话。

“高级连接”保留原访问凭据导入，适用于CLI/API或旧版演示服务；这类bearer凭据仍只在页面内存、刷新后需重新导入。旧8765本机进程暂未切换账号接口，页面提供“打开新版工作台”链接；旧演示工作空间仍保留独立合成数据。

## 身份与执行

页面“开始研究”调用新增`POST /research`，需同时具备`task:create`、`task:execute`、`report:register`；提交前检查模型凭据，创建后请求指定任务执行，成功结果自动登记固定报告。原`POST /tasks`和CLI submit仍只创建任务，兼容已有调用方式。可信本地运营者可发放：

```bash
.venv/bin/python -m cli.main managed identity-issue zhangsan research \
  task:create,task:read,task:cancel,task:execute,report:read,report:register,evaluation:read,evaluation:write \
  runtime/web-author.token --ttl 86400
```

API新增 `GET /session`、分页 `GET /tasks`、`GET /reports`、`GET /experiments` 和 `POST /tasks/<id>/execute`（body必须为空对象）。会话只返回身份、scopes和模板可用字段/限额/凭据存在标志，不返回配置、URL、密钥或对象路径。列表按token工作空间过滤。

点击“执行研究”仅请求指定任务；不领取其他工作空间或队列中其他任务。后端以最多2个本地调度线程启动既有spawn worker，SQLite并发/租约/预算仍是执行约束。重复同任务请求不再创建本地调度线程；容量满返回429。服务正常关闭时取消本服务请求中的任务，异常终止由租约和子进程watchdog约束。

页面开始研究时模型密钥缺失会在提交前拒绝，不产生无效排队任务；旧API已创建任务仍可取消。凭据“存在”只表示可开始尝试，不证明供应商授权或连接成功。模板与数据许可仍由运营者核定；真实模型费用遵守任务限制。

字段来源、公开模板接口、持仓复核证据绑定和逐项验收见[新建研究输入契约](research-inputs.md)。研究模板可在页面配置，来源许可与质量策略仍由可信运营配置提供；演示空间允许研究员修改公开研究模板，模型保持合成预设。

执行阶段来自LangGraph节点回调，只保存批准的阶段名称，不保存提示词、模型响应或任意metadata。页面每1.5秒刷新活跃任务及自动报告登记状态。自动报告意图保存在任务事件中；worker完成后按固定输入作者登记报告，重启补齐完成但未登记的报告，重复请求不重复登记。批准和发布仍需独立操作。

## 首页演示

“体验演示”进入每个浏览器会话独立的合成空间，无需创建正式账号。服务使用隔离的SQLite/报告目录和HttpOnly/SameSite会话cookie，所有接口走`/demo/`，不能访问正常任务、账号或模型设置。写入要求演示CSRF及同源Host/Origin。正式工作空间登录不会被演示身份替代。

演示的LangGraph实际执行七个分析阶段，离线脚本模型返回明确标注的合成文本，并通过同一TaskStore、调用预算、证据完整性、质量检查、ReportStore、EvaluationStore保存结果。演示子进程禁止Python socket连接，不调用真实行情或付费模型。普通“开始研究”会先固定演示计划，报告产生后可在“评估实验”绑定预测并登记预填价格。预设100→108及200→206只用于展示8%、3%和5个百分点的观察计算。

顶部“体验身份”可切换研究员、复核员、运营员，仅对演示空间生效。研究员完成任务后，切换复核员逐项核验、批准和发布，切回研究员观察结果；运营员查看调用账本和控制。跨演示会话的对象互不可见，退出演示撤销当前会话。每个进程同时缓存最多64个演示服务。

## 模型设置

本机模型配置入口为 **http://127.0.0.1:8783/#settings**。先在首页创建或登录管理员账号，然后打开“设置 → 模型配置”。模型API Key填在表单中；旧API访问凭据继续可在高级入口使用。之后启动新版本可自行选择端口，设置路径始终为`/#settings`。

先选择供应商，填写其控制台可用的模型ID（Azure填写部署名称）、核对接口地址，再填写API Key。支持OpenAI、DeepSeek、通义千问、GLM、MiniMax、Kimi、Claude、Gemini、OpenRouter、xAI、Mistral、Groq、NVIDIA、Azure、Ollama及通用OpenAI兼容接口。模型ID为自由输入，系统不保证供应商账户已开通默认名称。ChatGPT个人登录和AWS Bedrock仍通过原CLI/SDK使用。

“测试连接”仅校验所选层，另一层未填完时仍可先测试。它发出一次`Reply with OK.`请求，无SDK重试、最多64输出tokens，子进程总等待15秒；可能产生供应商费用。仅返回成功/失败类别、耗时和供应商给出的token usage，不回传响应正文、密钥或异常原文，不启动研究、不自动保存。成功仅证明短请求可用，工具调用及长研究另验。

“保存配置”写入本机SQLite中的不可变配置版本并更新工作空间当前版本；重新启动仍保留，新建研究任务与新评估计划立即采用该版本，无需重启。已有任务保留提交时的版本和密钥引用，修改/清除当前密钥不会改变已有任务；若需撤销旧密钥须到供应商控制台撤销，旧任务仍可取消。旧评估计划要求原模板hash，改变模型后需新建计划。

API Key以Fernet加密保存，解密文件为数据库旁的`<数据库名>.model-key`（权限600、Git忽略）；密钥不进入任务/报告/审计/浏览器存储，保存后输入框清空，只显示“已配置”。同供应商且同接口地址时留空保留密钥；更换供应商或地址时不会沿用旧密钥。“清除”只清除当前版本引用。没有保存配置的旧任务继续按原环境凭据执行；已保存配置的任务仅使用自己的密钥，不回退到进程环境。

设置读取要求`settings:read`，保存和连接测试要求`settings:write`；浏览器管理员具备写权限，其他角色只读。新增API为`GET /settings/models`、`POST /settings/models`、`POST /settings/models/test`。保存/测试携带`expected_version`，并发更新返回409，先刷新再操作。账号创建要求`accounts:manage`，角色从服务端固定scope映射取得，普通账号不能自行扩权。可信本地运营者仍可用原`identity-issue`发放独立设置scope。

浏览器认证新增`GET /auth/status`、`POST /auth/setup`（仅首个账号）、`POST /auth/login`、`GET /auth/session`、`POST /auth/logout`及管理员`GET/POST /accounts`。本机CLI在单工作空间模板服务开启账号入口；底层`make_server`默认仍仅bearer，需要显式`browser_accounts=True`。账号密码使用独立随机salt+scrypt保存hash；会话token仅保存hash，浏览器使用按端口命名的HttpOnly/SameSite=Strict cookie，7天有效，无密码/token写入localStorage。写请求需会话CSRF token且通过现有Host/Origin检查；登录接口还要求JSON和前端请求头。错误登录5次后同账号冷却60秒，密码计算最多2个并发。恢复备份撤销旧浏览器会话，保留账号密码hash，重新登录。

云接口需使用公开HTTPS/443，无用户信息、query或fragment；仅Ollama和通用兼容接口可用带高端口的loopback HTTP。发送前检查DNS公共地址，HTTP客户端禁止跨目标请求、重定向和环境代理；Gemini固定官方地址。此限制仍不能代替生产出口网关或DNS绑定防护。恢复备份不带解密文件，配置可查看，模型密钥需重新填写保存。

## 构建与安全边界

```bash
cd web
npm ci
npm run build
# 产物为 src/tradingagents/web/{index.html,app.js,style.css}
```

Python包数据清单包含这3个资源，sdist同时携带前端源文件及npm锁。修改前端后先重建，再打包Python分发；仅启动安装好的服务不需要安装npm依赖。

静态资源公开但固定白名单，任务和研究数据始终鉴权。接口只接受本机Host和同源Origin，启用CSP、no-store、no-referrer及nosniff，不返回CORS允许头。静态路径不读取任意磁盘文件；scope与身份由原token认证取得，不因进入网页而放宽自审或硬规则。该本机方案仍不等于公司OIDC、TLS或生产安全验收。

## 视觉与验证记录

设计采用深绿导航、浅灰内容背景、白色表格/表单、清晰中文层次，桌面为固定导航和双栏工作区，手机为抽屉导航与单列内容。首屏围绕“新建研究”和真实记录，未登录时计数显示未知，不展示虚构收益。控件有焦点状态，弹窗使用原生dialog，支持Escape、键盘及减少动效。

概念图服务在多次请求中只返回“生成中”占位图，未能提供可接受的设计参考；这些图片未进入产品或被当作已完成设计。实际页面按上述规范实现，使用内置浏览器和截图作视觉检查，不宣称与未生成的概念图达到像素一致。

验收结果在完成检查后补入[验证记录](../04-testing/validation-report.md)。真实研究密钥、数据许可、OIDC/云生产验收与长期金融有效性仍保留原边界。

实际已验证：31项后端专项、1486项全量离线及100项子测试；内置浏览器556px完成任务创建/取消，Playwright在1440px/390px完成导航与独立QA库的报告复核、发布、预测、价格观察、控制及对账，无页面运行错误。检查了首屏文案、绿/灰/白层次、中文标题与控件字号、表格/弹窗边界、手机导航/滚动，修正窄屏越界和状态请求竞态；最新wheel在仓库外加载web资源并返回HTTP200。

模型设置初始增量已验证：加密/保留/清除/版本冲突/权限拒绝/任务冻结/每层独立密钥/恢复后重新配置；本地HTTP模拟服务通过真实SDK完成一次连接成功及401失败。内置浏览器与1440px/390px Playwright完成保存、重连、只读、清除、还原、Azure字段与手机导航，无页面错误或横向溢出。该初始验证时主runtime设置为v0；用户后续配置的v1已保留，真实厂商授权本次未验证。

账号登录初始增量从首页验证创建/登录→工作台→全部页面→模型保存→刷新保持→账号创建→研究创建/取消→退出→复核员登录。默认研究日由会话提供UTC日期，与后端研究时间门禁一致，避免浏览器时区跨日使默认提交被拒绝。当时原库保留首次创建页；当前已有用户的两个账号，升级前后校验值一致，测试账号及模型密钥仅在独立QA库。本地密码登录不等于公司OIDC/云身份验收。

# 新建研究的字段来源与操作契约

实现日期：2026-10-25。每个字段明确来自系统预置、工作空间配置或本次输入；用户可以输入参数、修改配置、纠正错误并完成研究。当前入口为 **http://127.0.0.1:8783/**，原账号和数据继续使用。股票快捷流程与真实执行证据见[股票研究改进](stock-research-usability.md)。

本reference面向前后端/QA，由工程责任角色依据表单、ResearchOptions/ResearchProfile和服务校验维护；字段、来源或权限变更时及合并前复核。

## 字段与入口

| 字段 | 来源 | 用户操作 | 服务端约束 |
|---|---|---|---|
| 工作空间 | 登录身份 | 显示当前空间，退出后切换账号 | 请求空间须与身份一致 |
| 研究模板 | 系统初始模板、设置中保存的模板版本 | 选择、新增、复制、修改；创建页直达配置并保留草稿 | 设置读取/修改分别鉴权，版本冲突拒绝 |
| 证券标的 | 内置证券目录、模板批准清单 | 按市场和名称/代码搜索并点击选择；完整参数可输入批准代码 | 目录范围须由可信模板授权，不能扩大其他空间权限 |
| 资产类型 | 模板允许类型，系统支持股票/加密资产 | 选择适用类型；配置默认值和允许类型 | 只允许图支持的类型及模板范围 |
| 研究日期 | 服务UTC日期或演示初始日期；本次输入 | 日期选择或键入 | 日期有效且不得晚于当前UTC日期 |
| 预测期限 | 模板默认值；本次输入 | 键入交易会话数 | 整数1–2520，评估计划单独固定会话 |
| 对照基准 | 股票市场推荐值、模板默认值 | 快捷流程选择推荐SPY/沪深300/恒生指数；完整参数可键入 | 代码规范，报告与评估保持相同基准 |
| 报价币种 | 股票目录原始币种；专业流程模板默认值 | 快捷流程自动确定；专业完整流程可核对输入 | 不把显示币种替换为行情原币种，证据须一致 |
| 显示货币 | 系统预置美元/人民币 | 直接选择USD或CNY | 只有有效且留存的有日期汇率才换算，否则保留原币种 |
| 股票研究问题 | 系统预置 | 了解公司、寻找买入机会、核对持有理由、识别卖出风险 | 固定在任务中，不自动变成需要账户估值的持仓复核 |
| 研究路线 | 系统推荐快捷股票研究、专业完整路线 | 默认快捷，完整参数可切换 | 快捷最多8次调用（含重试），预算提交前核对；账户复核用完整路线 |
| 报告有效至 | 模板配置的有效天数；本次输入 | 日期选择或键入 | 不早于研究日，过期报告不可批准/发布 |
| 研究用途 | 模板允许用途；系统支持一般研究、事件研究、持仓复核 | 选择用途；持仓复核展开估值输入 | 持仓复核需要持仓和账户估值，不能凭空推断 |
| 实验名称 | 系统生成建议；本次输入 | 修改名称 | 字母数字/短横线/下划线，幂等冲突不新建任务 |
| 分析团队 | 完整路线的模板允许分析师；快捷路线固定四环节 | 完整路线可勾选；快捷路线只显示固定环节与来源 | 完整路线至少一个且不越过模板范围，快捷路线不显示无效团队控件 |
| 模型 | 设置中保存的快速/深度模型版本 | 显示当前模型并直达模型配置，返回后保持草稿 | 新任务固定当前版本，已有任务不回写 |
| 执行预算、调用上限、时长、输出上限 | 模板上限；本次输入 | 可以降低上限，需要提高时直达模板配置 | 本次限额不得超过模板，使用既有预算/租约机制 |
| 持仓上下文模式 | 系统支持未提供、明确空仓、有持仓、JSON导入 | 选择模式；表格添加/删除持仓；导入/粘贴JSON | 不把未提供当作空仓，拒绝重复标的和非有限数 |
| 持仓币种、现金、标的、数量、成本 | 本次输入；币种由研究参数提供建议 | 正常输入框与添加/删除行；数量可为负表示已有空头 | 币种与研究匹配，单标的合并，平均成本非负 |
| 账户净资产、当前数量、建议变动、估值价和日期 | 本次账户输入；日期/数量由本次研究持仓建议 | 持仓复核时输入并核对 | 使用本次留存的结构化行情绑定证据；价格、币种、日期或集中度不符会阻断 |

## 配置与持久化

“设置 → 研究模板”新增可操作配置页，支持模板名称/说明、批准标的、允许资产类型/用途、默认标的/币种/基准/期限/有效天数、分析团队与执行限额。初始模板来自运营配置文件，保存后以工作空间范围的不可变版本持久化；普通研究员可读取，管理员可写。合成演示的研究员可修改自己演示空间内的模板，不能借此修改正式工作空间或付费模型设置。

研究模板公开数据不得含模型密钥、私有路径或任意运行配置。配置改变后新建任务采用新值；任务与已登记评估计划保留原冻结输入，不迁移旧结果。设置返回和研究会话使用同一模板来源。

## 页面行为

字段旁显示“预置”“配置”“输入”来源，并提供简短说明。配置项存在使用者操作入口；下拉只展示真正支持的选项。选择模板同步默认值与可用团队，用户可以再修改。模型和模板配置往返保留本次草稿，提交失败保留全部输入。

校验在字段附近展示原因，并把焦点移到首个错误。服务端独立校验所有输入、权限、范围和上限；错误响应只给字段位置与安全原因，不回传密码、密钥或原始输入。提交期间阻止重复请求，成功后进入实际任务进度和报告。

## 验收要求

至少两轮独立验收，每轮覆盖：

1. 从首页登录，新增/复制/修改研究模板，刷新后配置仍保留。
2. 对创建页每个输入框和下拉选项逐项操作，核对来源、值、边界和字段错误。
3. 模板/模型配置往返后草稿保留；改变默认值实际用于下一份研究。
4. 结构化持仓添加/删除/导入、空仓与未提供区别、持仓复核估值、分析师选择与限额。
5. 提交实际执行、报告输入与冻结任务一致；演示的资产、币种、用途和分析师选择实际生效。
6. 越权、超限、未批准标的、无效日期/币种、重复持仓和配置冲突均正确拒绝。
7. 桌面与手机布局、键盘操作、无空白/框架覆盖层/应用错误、安装包及重启持久化。

## 已实现接口与留存

- `GET/POST /settings/research`：读取公开模板及真实支持选项，保存工作空间模板版本。`ResearchSettingsInput` 使用 `expected_version` 防止覆盖他人修改。模板标识创建后固定，复制时可输入新标识。
- `GET /session`：使用与设置一致的模板来源、版本、默认值、执行上限、模型名称和币种/基准建议。正式模板初始来自运营文件，演示模板初始来自合成配置。
- `POST /research`：`options` 可选择允许的团队并降低调用、时间、输出和预算上限；原顶层任意运行配置仍不接受。前后端分别校验日期、标的、持仓、估值和范围。字段错误只返回位置与安全原因。
- `allocation_valuation` 接收账户估值，无需用户寻找证据哈希。执行留存原始账户输入，再将其绑定到本次结构化行情证据；币种、日期、价格、做空或集中度不符会阻断发布。
- 任务与报告详情可展开“提交时的研究输入”，核对固定团队、限额、模型、持仓和账户估值。修改设置不回写旧任务。

## 已完成的浏览器验收

完整操作进行了两组桌面/手机验收，共四轮（1440×1000、390×844）。每轮实际新增、复制、编辑并刷新模板；逐项改变字段、资产类型、用途、币种建议与自定义币种、团队选择、限额和全部持仓模式；验证错误定位、焦点、草稿配置往返、持仓增删与JSON文件导入。每轮执行事件研究、一般研究和持仓复核，共12份实际合成任务；核对调用数、冻结输入、报告及3%目标仓位计算。四轮均无应用脚本错误，无页面或弹窗横向溢出。

内置浏览器首次打开后出现“No URL is loaded”和 `net::ERR_ABORTED`，恢复标签页后点击仍没有状态变化；后续使用现有Playwright完成实际控件操作和固定尺寸校验。检查记录位于本地 `runtime/logs/inputs-browser-final.txt`、`runtime/logs/inputs-browser-delivery.txt`，结果位于 `runtime/inputs-qa/input-rounds.json`。这些本地运行记录与截图不进入发布源码。

正式数据库的两个已有账号和任务记录在更新前后按哈希/数量核对一致；未添加测试账号或模型密钥。原8780停止操作被自动审批拒绝（担心影响已有入口、没有针对该进程的明确终止授权），因此保留该服务，新版8781使用同一数据库。真实付费模型和外部行情没有在这次验收中调用。

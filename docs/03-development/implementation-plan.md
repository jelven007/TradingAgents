## 3. 每包完成定义

代码、契约、权限/幂等/错误边界、关键测试、日志指标、数据迁移/回滚和用户说明齐备；追踪矩阵更新状态并链接测试证据。数据库迁移必须有旧版本兼容期和回滚方案；数据迁移先dry-run、逐条统计校验、保留原文件，禁止默认删除旧文件。

## 4. 发布门禁与资源

S1先选少量批准标的与受控用户，不开放所有Yahoo覆盖市场。按模型、来源、语言与分析师深度采样真实任务，测量质量/耗时/费用/失败；预算与并发由结果决定。受控试运行的“分析任务成功率”不替代证据质量或安全测试。

需要产品负责人、后端/核心工程、QA、SRE、模型/数据负责人和安全角色；可以兼任但必须明确签署责任。身份/secret manager、数据许可、托管DB/对象存储/队列是关键外部依赖，应在S1前确认。

# 产品需求与验收基线

状态：2026-10-25，`PROD-DOC-2.0`。本文件是需求编号唯一来源，面向产品、工程和QA，由产品责任角色维护；功能或验收口径变化时同步更新，每次合并前复核。本地功能依据源码与[验证记录](../04-testing/validation-report.md)，生产准入仍需业务签署；状态及责任目录见[文档控制](../07-governance/document-control.md)。

## 1. 产品目标与边界

面向入门投资者及内部研究员，以“选择股票和问题，系统返回可解释判断”为主路径；复核员、管理员、运营和运维分别处理质量、配置、使用及服务保障。输出买入、增持、持有、减持、卖出的研究观点、支持/反方理由、主要风险和重新判断条件，不接受券商指令、不管理资金、不承诺收益或优于市场的胜率。

成功分别衡量输入易用性、预算内收尾、资料缺口诚实性、依据可追溯及复核状态。内置美股、沪深北A股和港股源目录用于选择，不等于每只证券都能取得行情、全球覆盖或可交易。可信模板决定目录授权；完整图和crypto保留专业入口，不把单一NVDA真实样本外推到所有市场或金融有效性。

本机角色是管理员、研究员、复核员、运营员；任务/报告按工作空间及scope授权，个人关注和最近研究按本人隔离。管理员管理账号和模型，不能自审；普通研究员不能保存真实模型。生产OIDC、账户级持仓授权及独立模型管理员/SRE职责为待建目标，不能套用成本机已实施权限。

## 4. 范围与业务决策

必须在生产S1前确认用户/角色、模型地区、来源许可、费用、保留期、OIDC和运行责任。当前loopback单机、单服务工作空间，默认通用deadline1800秒；示例daily模板为900秒、10,000,000微美元预算、每次500,000微美元预留。快捷UI默认调用上限8，专业完整上限来自模板。预留不是账单，累计准入不是月预算；本机并发2不构成吞吐/SLO承诺。

候选保留策略：任务/报告/审计365天，原始数据90天（受供应商许可约束），可重建缓存7天；详细限制见[数据治理](../02-architecture/model-and-data-governance.md)。市场、用途或授权范围变化必须重新评估。

订单、确定性交易风控、成交、清算、资金、移动应用不在 S0–S2 范围。研究评级的 `Buy` 不能直接映射生产订单。

## 5. 优先级与完成定义

P0 是进入受控服务试运行的必要能力，P1 在试运行稳定后扩展。单条需求完成需同时具备实现、测试、运行证据、文档及责任人确认；现有 SDK 功能只证明核心能力，不等于对应平台需求全部完成。阶段完成条件见[验收清单](../04-testing/acceptance-checklist.md)。

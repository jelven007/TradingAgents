# 业务流程与领域规则

状态：2026-10-25本机当前流程，云目标单独注明。读者为投资者、研究员、复核员和产品；产品责任角色依据`application/service.py`、`worker.py`及存储状态维护，每次行为/权限变化与发布前复核。

## 1. 研究任务

用户登录后搜索并点击股票，选择了解公司、买入机会、持有理由或卖出风险。原始币种和市场基准自动带入，USD/CNY显示和期限可修改；其他参数默认由系统/模板提供，完整参数可展开。工作空间与作者来自身份，不能由输入指定。`POST /research`校验权限/字段/预算，固定当前模板、模型、证券和意图，启动指定worker，成功后自动登记报告。本机直接领取SQLite任务，不使用outbox；云投递为后续设计。

任务状态为`queued → running → succeeded | failed | cancelled | timed_out`。租约重领产生新attempt；普通失败后的“使用推荐配置重新研究”创建新任务，保留旧输入和结果，不是覆写旧attempt。快捷路线固定资料分析、多方、反方、风险综合，含重试最多8次。任务succeeded只说明结果已保存并通过完整性接受；`research_status=insufficient`仍可能是已成功保存的资料不足报告。

## 2. 复核与发布

固定报告状态为`draft → approved → published → withdrawn`；草稿可退回`rejected`或撤回。`expired`为读取时单独标志，`needs_review/blocked`是quality状态，并不存在数据库状态`review_required`。作者不得自审；全部review项需确认，block项不能豁免，到期或损坏文件不能批准/发布。Insufficient、REVIEW、许可未知和关键价格问题由质量规则阻断，不能将“执行完成”显示为“已复核”。修订产生新版本，保留原文及supersedes关系。

“报告发布”表示授权工作空间内可见，不表示订单批准或交易执行。初期不提供公共外链。

## 3. 持仓上下文

未提供持仓是未知账户，`positions=[]`是明确空仓；表格或JSON导入固定币种、现金、标的、数量和成本，执行不回写。点击“核对持有理由”仍是股票研究问题，不要求账户净资产；专业`portfolio_review`才需要持仓和账户估值，价格与执行留存证据核验。显示货币换算不是账户跨币种估值服务。

## 4. 历史研究与评估

本机契约是daily，研究日按服务UTC日期校验，不能声称市场盘中cutoff或完整公开时间证明。消费时间observed_at与known_at/fetched_at/published_at分开，未知保留null。快捷历史研究不把当前公司/新闻快照作为历史可知数据；完整市场时区/instant档案为生产待建。

回测由实验负责人冻结 ticker/date 网格、配置、快照集、重复采样策略和 benchmark。各单元结果分别保存；无法分析、未结算与 REVIEW 单列，不可排除后只呈现成功结果。对照实验必须隔离记忆，不利用较晚实验的收益或复盘污染较早时点。

当前上游回测只评价独立评级；对收益精度、非归档文本和持仓不演化的限制必须随评估结果展示。

## 5. 反馈闭环

用户反馈绑定 task_id、report_version、引用证据、问题分类和可复现说明。运营排查后分派数据、模型或工程负责人；修复需对应回归案例、模型评估和新版本记录。关闭反馈需要给出处理结果及新旧版本影响，不以“重跑看起来正常”代替根因。

## 6. 异常判定

| 情况 | 行为 | 禁止行为 |
|---|---|---|
| 非法 ticker / 未来日期 | 在创建阶段拒绝 | 已发起模型后才校验 |
| 供应商不可用 | 按冻结链降级，记录数据质量；关键证据不足则复核或失败 | 把断网解释为公司无数据 |
| 模型格式失败 | 记录结构化/文本回退，评级不可解析则 REVIEW | 自动转成 Hold |
| 预算用尽 / 超时 | 停止新增调用，保留进度及失败原因 | 无限自动重试 |
| checkpoint 不匹配 | 托管新attempt从新目录运行，旧状态保留；旧SDK按自身checkpoint规则 | 混用新旧模型结果 |
| 用户取消 | 协作式取消，保存已消耗成本；外部请求可能已发生 | 承诺撤销已发出的付费调用 |

## 7. 回访与来源缺口

报告先展示观点、条件和留存价格；USD/CNY换算单列汇率日，无有效汇率保留原币种。原文节选可展开，读取重新核验固定hash，不再调用模型。个人关注上限100，笔记上限4000字符；重复关注保留笔记，移除会删除该对象笔记。另一账号的最近研究/关注不可混入本人首页，报告仍按工作空间范围授权。数据源/模型失败保留安全类别，不能虚构价格或新闻；正常Hold、资料不足、质量阻断和待复核分别解释。

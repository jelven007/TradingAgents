# 安全、权限与审计设计

状态：2026-10-25。面向工程/安全/SRE，安全责任角色依据身份、模型凭据及HTTP实现维护；权限、供应商地址、数据路径变化或合并前复核。旧CLI/SDK是可信工具，本机managed有密码/scopes及可撤销token。研究请求不接受操作者或任意config/backend_url/策略/路径，限额只能在模板范围内降低；管理员通过独立设置权限保存模型。公司OIDC、TLS、全量加密和生产出口仍待建。

## 1. 信任边界

入口认证使用公司 OIDC，验证签名、issuer、audience、过期时间并映射工作空间角色。API/worker 到数据存储使用独立服务身份；模型和数据供应商是外部边界，供应商内容与模型输出都不可信。

授权至少覆盖任务查询、报告、证据、下载、持仓、实验、复核和配置管理；数据查询总是显式带 workspace_id，S2 用 PostgreSQL RLS 增加纵深防护。后台任务不得使用无范围超级身份处理用户请求。

## 2. 角色矩阵

| 角色 | 任务与报告 | 持仓/证据 | 配置/审计 |
|---|---|---|---|
| researcher | 本工作空间创建、读报告、提交反馈 | 授权账户及证据 | 读取已生效配置 |
| reviewer | 本工作空间复核发布固定版本 | 复核所需数据 | 查看复核审计 |
| model_admin | 读取脱敏评估及配置 | 默认不可读持仓 | 提交配置；生效需负责人批准 |
| operator | 脱敏使用与反馈 | 默认不可读原始内容 | 运营指标 |
| sre | 任务状态及故障分类 | 默认不可读正文/持仓 | 部署、服务观测；审计权限另授 |

紧急访问需时限、工单与完整审计；本地实现严格禁止作者自审，无单用户豁免。身份subject统一小写，不能用大小写变体规避；token最长一天，普通用户不应拥有数据库文件权限。

本机浏览器账号另有管理员/研究员/复核员/运营员角色。首次本机初始化只能创建一个管理员账号；随后账号创建需`accounts:manage`。管理员具备现有页面功能，其他角色按固定scope映射显示导航。业务subject使用服务端随机账号ID，输入用户名不能冒充既有作者；管理员仍受作者自审规则限制。这是本机模式，不能代替上述生产OIDC或组织角色矩阵。

工作空间授权与本人数据隔离不同：任务/报告读取按workspace和scope，个人关注/笔记/最近研究按subject过滤。新增证券搜索需task:read，可信模板allow_listed_stocks决定目录范围；公开研究模板不能改写来源许可或扩大该授权。显示USD/CNY不会改写原始行情币种，也不新增交易权限。

## 3. 主要威胁与控制

| 威胁 | 控制 | 证据 |
|---|---|---|
| 跨租户ID引用 | 服务层授权 + workspace过滤 + RLS；对象签名下载期限≤5分钟建议值 | task/report/snapshot全覆盖负面测试 |
| SSRF/密钥外泄 | backend endpoint 由管理员注册并限制域名、协议和出口；禁止普通用户配置URL | metadata/private IP/redirect绕过测试 |
| 提示词注入 | 证据作为引用数据而非指令；工具白名单、参数范围、只读能力和调用预算 | 恶意新闻/社交语料回归 |
| HTML/XSS | 安全渲染模型文本、禁止脚本与危险URL、CSP、报告域与管理域隔离 | HTML渲染安全测试 |
| 路径穿越/对象覆盖 | 服务生成UUID路径，ticker规范化，不接受本地路径 | 路径及符号回归测试 |
| 共享配置与记忆串扰 | 独立graph实例、冻结配置、工作空间/实验隔离、租约 | 并发与串扰测试 |
| 费用滥用 | 请求配额、预算预留、模型白名单、总deadline、调用计数 | 429/预算/重试故障测试 |
| 依赖供应链 | 版本锁、来源审查、镜像摘要、漏洞扫描、SBOM | 发布流水线记录 |

完整威胁门禁仍是生产目标。本地system已覆盖跨空间任务/报告/实验/预测/观察、权限不足、过期/撤销、请求注入拒绝、自审、独立audit权限、loopback HTTP和内容篡改；路径、scrub及HTML用例保留。尚未完成公司OIDC、签名下载、账户级权限、全面SSRF/供应链或真实环境安全验收。

## 4. 凭据与数据

本地 `.env` 仅用于开发，权限600，不进入Git或镜像；生产由secret manager注入，短期凭据优先，按服务身份最小授权。容器最终层只复制安装环境；构建context排除 `.env`、`.env.*`、运行数据和本地工具。

常规日志和错误响应不记录密钥、完整backend URL或原始敏感文本；固定任务/输入及报告摘要确实保留用户提交的持仓，证据目录保留实际消费输出，必须按工作空间授权及文件权限保护，不能把它们当作脱敏日志。模型请求可能含研究内容/持仓，组织部署需确认发送范围与供应商许可，不默认上传账户标识。

目标审计需独立写权限、保留策略和防管理员篡改控制。本地SQLite trigger禁止应用更新/删除记录，复核有hash链，计划/预测/观察有hash关联；OS管理员仍能改文件或移除trigger，不属于WORM。访问审计与业务操作不在同一事务，生产原子审计仍待建。备份包含数据库输入配置，恢复副本撤销全部旧token。删除/到期清理遵守[模型及数据治理](model-and-data-governance.md)。

模型设置增加独立`settings:read/write`，写入不可变公共版本和Fernet密文表；解密文件权限600，不进入Git、共享备份或任何HTTP响应。进程内使用ContextVar注入每层凭据，不改环境变量；旧任务引用原版本。普通研究角色不能保存或测试模型。留空保留密钥要求供应商及endpoint均一致；换地址不自动发送旧密钥。删除当前密钥不销毁被旧任务引用的凭据，实际撤销须在厂商侧完成。

本机设置接口拒绝凭据内嵌URL、非HTTPS云接口、私网/metadata字面地址与低端口本机服务；连接测试/模型请求前核对DNS公共地址，HTTP传输禁重定向、跨目标请求和环境代理，Gemini固定官方地址。DNS核对与实际连接存在时间窗口，仍需生产出口绑定/网关；当前能力不能宣称完整SSRF或云密钥管理验收。连接测试只有一次最多64输出tokens请求、无重试、独立进程15秒总等待，上限2个并发。

浏览器账号密码采用每账号随机salt+scrypt（N=16384/r=8/p=1），不保存或返回明文。会话token随机生成，数据库只存hash，cookie以端口命名、HttpOnly、SameSite=Strict、有效期7天。写操作检查会话CSRF token和同源Host/Origin，登录/初始化要求JSON及前端请求头；两条密码计算并发、同账号5次失败后冷却60秒。退出和备份恢复撤销浏览器会话；账号hash保留以重新登录。HTTP仅loopback，本机密码/会话不应作为网络生产身份方案；TLS/组织认证及账号生命周期另验。

## 5. 发布条件

NFR-004 需跨租户、日志密钥、下载授权、SSRF、报告渲染及提示词注入用例通过；漏洞扫描无未处置高危且无可利用阻断项。安全设计评审、数据许可与供应商合同确认是服务试运行门禁；本次没有执行完整安全审计。

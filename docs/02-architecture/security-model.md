# 安全、权限与审计设计

状态：生产目标。现有 CLI 是单用户研究工具，没有服务级认证与租户授权。服务化不得直接暴露任意 config、backend_url 或磁盘路径。

## 1. 信任边界

入口认证使用公司 OIDC，验证签名、issuer、audience、过期时间并映射工作空间角色。API/worker 到数据存储使用独立服务身份；模型和数据供应商是外部边界，供应商内容与模型输出都不可信。

授权至少覆盖任务查询、报告、证据、下载、持仓、实验、复核和配置管理；数据查询总是显式带 workspace_id，S2 用 PostgreSQL RLS 增加纵深防护。后台任务不得使用无范围超级身份处理用户请求。

## 2. 角色矩阵

| 角色 | 任务与报告 | 持仓/证据 | 配置/审计 |
|---|---|---|---|
| researcher | 本工作空间创建、读报告、提交反馈 | 授权账户及证据 | 读取已生效配置 |
| reviewer | 本工作空间复核发布固定版本 | 复核所需数据 | 查看复核审计 |
| model_admin | 读取脱敏评估及配置 | 默认不可读持仓 | 提交配置；生效需负责人批准 |
| operator | 脱敏使用与反馈 | 默认不可读原始内容 | 运营指标 |
| sre | 任务状态及故障分类 | 默认不可读正文/持仓 | 部署、服务观测；审计权限另授 |

紧急访问需时限、工单与完整审计；报告批准者原则上与创建者分离，单用户试运行例外须记录。

## 3. 主要威胁与控制

| 威胁 | 控制 | 证据 |
|---|---|---|
| 跨租户ID引用 | 服务层授权 + workspace过滤 + RLS；对象签名下载期限≤5分钟建议值 | task/report/snapshot全覆盖负面测试 |
| SSRF/密钥外泄 | backend endpoint 由管理员注册并限制域名、协议和出口；禁止普通用户配置URL | metadata/private IP/redirect绕过测试 |
| 提示词注入 | 证据作为引用数据而非指令；工具白名单、参数范围、只读能力和调用预算 | 恶意新闻/社交语料回归 |
| HTML/XSS | 安全渲染模型文本、禁止脚本与危险URL、CSP、报告域与管理域隔离 | HTML渲染安全测试 |
| 路径穿越/对象覆盖 | 服务生成UUID路径，ticker规范化，不接受本地路径 | 路径及符号回归测试 |
| 共享配置与记忆串扰 | 独立graph实例、冻结配置、工作空间/实验隔离、租约 | 并发与串扰测试 |
| 费用滥用 | 请求配额、预算预留、模型白名单、总deadline、调用计数 | 429/预算/重试故障测试 |
| 依赖供应链 | 版本锁、来源审查、镜像摘要、漏洞扫描、SBOM | 发布流水线记录 |

这些测试大部分是目标门禁，不表示当前测试已全部覆盖。现有安全相关事实仅包括 ticker 路径保护、输出部分scrub、HTML处理、数据层错误和文件锁等。

## 4. 凭据与数据

本地 `.env` 仅用于开发，权限600，不进入Git或镜像；生产由secret manager注入，短期凭据优先，按服务身份最小授权。容器最终层只复制安装环境；构建context排除 `.env`、`.env.*`、运行数据和本地工具。

日志、report manifest与审计不记录密钥、完整backend URL、持仓明细或供应商原始敏感文本。日志使用字段白名单，debug仅在隔离环境启用。模型请求可能包含持仓与研究内容，需先确认公司数据出境/供应商合同与许可；不默认允许发送个人或账户标识。

审计记录受独立写权限、追加语义、保留策略和完整性哈希保护，普通管理员不可删除。删除/到期清理遵守供应商许可及公司政策，见[模型及数据治理](model-and-data-governance.md)。

## 5. 发布条件

NFR-004 需跨租户、日志密钥、下载授权、SSRF、报告渲染及提示词注入用例通过；漏洞扫描无未处置高危且无可利用阻断项。安全设计评审、数据许可与供应商合同确认是服务试运行门禁；本次没有执行完整安全审计。

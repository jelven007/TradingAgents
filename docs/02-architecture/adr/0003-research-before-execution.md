# ADR-0003：研究平台先行，交易执行独立立项

- 日期：2026-10-23
- 状态：需求范围建议；本次代码继续仅提供研究能力
- 关联：FR-003、FR-007、FR-009
- 维护：产品/架构责任角色面向工程/研究员，2026-10-25复核；研究或订单范围变化时更新。

## 背景

上游README描述模拟交易所执行，但代码只产生研究评级、交易建议、文件报告和独立决策评估。没有订单、成交、资金账本、手续费、滑点或broker adapter。

## 决策

S0–S2只建设研究、证据、人工复核、评估和运营平台。报告批准只决定可见性，不转化为券商指令。Trader/Portfolio Manager是LLM研究角色，不承担真实账户的确定性风险控制。

## 后续执行系统进入条件

独立产品需求、监管/业务范围确认、账户授权；确定性仓位与风险限额、价格/交易日历与停牌规则；订单幂等、成交回报、资金及持仓对账；纸面交易和故障/熔断/撤单演练。只有这些门禁完成后才能讨论真实资金接入。

## 权衡

阶段性减少功能范围，但明确可验收能力，避免把研究回测alpha解释为含交易成本的策略净值。后续订单域不得侵入现有回测评分模块。

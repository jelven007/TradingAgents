# ADR-0004：入门股票研究采用固定有界路线

- 日期：2026-10-25
- 状态：本机已实施并用真实供应商单样本验证；生产准入另验
- 读者/责任：工程、模型、QA；架构责任角色维护
- 关联：FR-016、FR-017、FR-018、FR-019、NFR-010
- 复核：模型能力、预算、数据契约或路线变化时及每次合并前

## 背景

两个真实NVDA任务在20次模型调用后耗尽10,000,000微美元预算；40次调用上限不代表预留预算能容纳40次。用户还需手工配置股票和报价币种，已有美股研究被标为CNY。完整图的分析深度与入门默认流程之间存在成本和易用性差距。

## 决策

用户通过内置证券目录选择股票与问题，按市场推荐基准，原始币种自动确定，USD/CNY仅作为独立显示币种。默认快捷路线先采集真实结构化资料，固定执行资料分析、多方、反方和风险综合，每环节最多尝试两次、SDK重试0，总计最多8次；提交前预留预算必须可容纳全部尝试。

预算、deadline、租约、调用账本和固定报告完整性继续使用原托管管线。没有关键价格或完整模型结果时返回Insufficient，保留实际资料和安全失败类别；不得虚构价格、替换合成来源或伪装Hold。完整专业图仍可选择，账户portfolio_review保留显式估值要求。

## 替代与取舍

只提高预算会增加费用且不消除默认路线不确定长度；把全部配置交给用户不能解决入门负担；隐藏失败并强制评级会损害可解释性。固定路线减少讨论轮数和工具探索，保留多空与风险结构，但不能证明预测准确度或所有标的的数据覆盖。目录是有日期的名称元数据，不是实时行情或全世界股票。

## 验证与后续

`tests/system/test_guided_stock.py`覆盖目录、权限、币种、预算、网络/解析/截断、异常行情与完整性。真实模型在1200输出额度下空正文，系统生成不足报告；恢复模板已有4096额度后4次收尾，费用上限不变。真实来源许可未声明，最终报告仍为质量阻断、待复核草稿。三屏UI、逐字段配置和安装重启证据见[验证记录](../../04-testing/validation-report.md)；不外推为金融胜率或生产SLO。

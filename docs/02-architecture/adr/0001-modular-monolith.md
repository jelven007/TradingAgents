# ADR-0001：模块化单体与独立 worker

- 日期：2026-10-23
- 状态：2026-10-25本机模块化服务与独立spawn worker已实施；云选型待技术负责人确认
- 关联：FR-002、NFR-002、NFR-008

## 背景

现有仓库是可复用研究核心，模型/行情调用耗时且外部服务波动较大；没有证据需要全面微服务，但Web请求内运行graph会阻塞且放大可变状态共享风险。

## 决策

控制面、任务、审计、配置保持模块化服务，研究由独立worker进程执行；本机SQLite为状态真相、文件hash为结果完整性锚点，每任务独立graph/attempt，租约条件提交。PostgreSQL、队列至少一次投递和outbox为云目标，尚未接入。

## 替代与后果

同步Web内执行实现简单但无法可靠取消、恢复或隔离。全面微服务可独立扩缩却增加事务、契约和维护成本。采用单体使版本一致、测试集中，代价是必须主动约束模块依赖。只有真实负载、团队边界或资源瓶颈证明价值时拆分模型网关/评估服务。

## 验证

DEV-020/030已用本机离线测试验证幂等、worker死亡、租约超时和旧attempt拒绝，真实快捷研究也在spawn路线完成。云重复投递、集群一致性和扩容压测仍待验收。工程责任角色在存储/worker边界变化时更新本记录，合并前核对验证证据。
